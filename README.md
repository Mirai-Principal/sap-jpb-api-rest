# SAP API REST

Estructura base para una API REST con Express y TypeScript.

## Requisitos

- Node.js 20 o superior
- npm

## Instalacion

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Documentacion

Con el servidor en ejecucion:

- Swagger UI: `http://localhost:3000/docs`
- OpenAPI JSON: `http://localhost:3000/openapi.json`

## Build

```bash
npm run build
npm start
```

## Endpoints iniciales

- `GET /`
- `GET /api/v1/users`
- `GET /api/v1/users/:id`
